# Keyboard Shortcuts

## File

| Shortcut | Action |
|---|---|
| Ctrl+O | Import data |
| Ctrl+Q | Exit |

## Navigation

| Shortcut | Page |
|---|---|
| Ctrl+1 | Data |
| Ctrl+2 | Preprocessing |
| Ctrl+3 | DTM / TF-IDF |
| Ctrl+4 | Descriptive Statistics |
| Ctrl+5 | Bivariate Analysis |
| Ctrl+6 | Regression |
| Ctrl+7 | PCA |
| Ctrl+8 | Factor Analysis |
| Ctrl+9 | Clustering |

Topic Modeling, Sentiment, and Machine Learning are available from the sidebar and the Analysis
menu.

## View and help

| Shortcut | Action |
|---|---|
| Ctrl+R | Toggle the Results Viewer |
| F1 | Open the User Guide |
| Ctrl+Mouse wheel | Zoom the figure canvas when the matplotlib toolbar is active |

## Results Viewer

Use the selected table and figure combo boxes to switch results. Export buttons open standard
save dialogs. The matplotlib toolbar provides home, back, forward, pan, zoom, and save controls
for figures.
